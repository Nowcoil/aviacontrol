# АвиаКонтроль 2.0

Личный офлайн-журнал входного контроля авиационных колёс и тормозов. React + TypeScript + Vite, IndexedDB, service worker. Серверной базы, регистрации и синхронизации нет.

Приложение: https://nowcoil.github.io/aviacontrol/

**Уже пользуетесь версией 1? Сначала сохраните JSON-копию на каждом телефоне.** Полная инструкция по обновлению, сохранности данных, новым функциям, тестам и ограничениям: [ОБНОВЛЕНИЕ-2.md](ОБНОВЛЕНИЕ-2.md).

## Запуск

Node.js 22.12+:

```sh
npm ci
npm run dev
```

Проверки и готовая версия:

```sh
npm test
npm run build
npm run preview
```

Разработка: адрес из терминала, обычно http://localhost:5173. Готовая версия: http://localhost:4173. Для проверки service worker используйте собранную версию, а не режим разработки. При ограничениях загрузчика конфигурации Vite можно добавить `-- --configLoader runner` к команде сборки/предпросмотра или тестов.

В `.github/workflows/pages.yml` настроены тесты, сборка и публикация GitHub Pages при изменении `main`. Не загружайте в репозиторий пользовательские JSON-копии и рабочие журналы.

## Использование

- Выберите дату журнала, затем заполните авиакомпанию, P/N и S/N компонента. Для колеса также обязательны P/N и S/N шины; наварка и примечания необязательны.
- Номера переводятся в верхний регистр при вводе, вставке и сохранении. Авиакомпания и примечания сохраняют регистр.
- Собственные подсказки ищут совпадения в справочниках и истории. Выбор заполняет только текущее поле; колесо и шина не связаны. Ручной ввод новых значений доступен.
- После сохранения форма полностью очищается, дневной список остаётся. Черновик сохраняется локально и восстанавливается со своей датой.
- Пустая форма в автоматическом режиме использует текущую дату устройства. Черновик, редактируемая запись и сознательно выбранная дата не переносятся автоматически. Кнопка «Сегодня» возвращает автоматический режим.
- Включите «Искать и показывать все даты», чтобы искать по всей истории. Редактирование и удаление доступны в карточках записей.
- Авиакомпании и независимые справочники P/N колёс/шин доступны в своих разделах. Удаление из справочника не удаляет историю; массовое переименование истории требует отдельного выбора и подтверждения.
- «Внесено в 1С» — только личный флажок: в 1С ничего не отправляется, в XLSX отметка не включается.

## Месячный Excel

В разделе «Данные и установка» сохраните имя сотрудника. В журнале нажмите «Excel за месяц», выберите месяц и год и скачайте XLSX. Название: `Антон_Ноябрь_2026.xlsx`. Каждый день с поступлениями получает свой лист, пустые дни не включаются. Выгрузка включает все сохранённые записи месяца независимо от поиска и выбранной даты журнала. Повторная выгрузка учитывает новые записи, исправления и удаления, не изменяя базу.

Все девять столбцов печатаются на А4 в альбомной ориентации на одну страницу по ширине, без ограничения страниц по высоте. Заголовки повторяются при печати; длинный текст переносится. Очень длинные примечания продолжаются в строках с `↳`, чтобы не обрезать текст. Номера — текст, включая ведущие нули; макросов и надстроек нет.

Файл находится в «Загрузках»/«Файлах» телефона. Отправьте его на ПК через «Поделиться», Quick Share, почту/мессенджер или USB. Приложение само ничего не отправляет.

## Резервные копии

В конце рабочего дня сохраните текущую запись → «Данные и установка» → «Сохранить копию JSON». Проверьте скачивание и перенесите копию **за пределы телефона**. Excel не заменяет JSON. Копия версии 2 включает журнал, отметки 1С, справочники и имя сотрудника; черновик в обычную копию не входит.

Для восстановления сначала скачайте текущую копию, затем выберите JSON и подтвердите объединение. Старые копии версии 1 поддерживаются. При совпадении id записи сохраняется версия с более поздним `updatedAt`; остальные записи не удаляются. Справочники объединяются. Импорт не заменяет текущий черновик и уже заданное имя сотрудника. Старая копия может вернуть ранее удалённые записи.

## Установка и офлайн

**Android:** откройте опубликованный HTTPS-адрес в Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

**iPhone:** откройте тот же адрес в Safari → «Поделиться» → «На экран Домой».

Первое открытие и обновление требуют интернета. После загрузки откройте приложение в авиарежиме, закройте и снова откройте, проверьте журнал. Данные привязаны к браузеру и адресу. Другой телефон/браузер имеет независимый журнал. Не удаляйте данные сайта, не используйте инкогнито и не переустанавливайте приложение без внешней JSON-копии.

## Схема и тесты

База `aviacontrol-local`, версия IndexedDB 1, хранилища `entries` и `settings` сохранены. Новые справочники, имя и внутренний снимок до обновления хранятся дополнительными ключами в `settings`. Инициализация не переписывает старые поступления. Основные проверки: `src/core.test.ts`, `src/upgrade.test.ts`.

Точные результаты, изменённые файлы, ограничения Excel 2010 и проверки на физических телефонах приведены в [инструкции обновления](ОБНОВЛЕНИЕ-2.md).
