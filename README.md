# АвиаКонтроль

Личный журнал входного контроля авиационных колёс и тормозов. React + TypeScript + Vite, IndexedDB, устанавливаемое офлайн-PWA. Нет серверной части, аккаунтов, аналитики и облачной базы. Проект WeekendWork не используется и не изменяется.

## Быстрый запуск на компьютере

Установите Node.js 22.12+ (либо актуальную LTS-версию). Откройте терминал **в этой папке**:

```sh
npm ci
npm run dev
```

Откройте адрес, который покажет терминал (обычно http://localhost:5173). Это режим разработки, не проверка офлайна.

Для готовой версии:

```sh
npm test
npm run build
npm run preview
```

Откройте http://localhost:4173. Папка `dist` содержит готовое приложение; открытие `index.html` двойным щелчком не поддерживается. Сервер предпросмотра нужен только для тестирования на ПК.

## Как установить на Android

1. Разместите **содержимое `dist`** на постоянном статическом HTTPS-адресе (например, GitHub Pages). Это раздача файлов приложения, без базы данных или обработки записей на сервере. Адрес компьютера `http://192.168.…` на телефоне не подходит для service worker.
2. Откройте этот HTTPS-адрес в обычном Chrome на Android, с интернетом. В разделе «Данные и установка» дождитесь «Приложение готово к работе офлайн» при первой загрузке.
3. Меню Chrome ⋮ → «Установить приложение» / «Добавить на главный экран». Если в приложении доступна кнопка «Установить приложение», можно использовать её.
4. Откройте с рабочего стола, включите авиарежим, закройте и снова откройте приложение. Проверьте открытие журнала, сохранение и повторный запуск. Первый запуск и обновление требуют интернета; последующая работа — нет.

PWA работает на одном телефоне. У другого браузера, профиля и адреса будет отдельный журнал. Сохраняйте постоянный адрес: при переезде сначала сделайте JSON-копию, затем импортируйте её по новому адресу. Приложение не устанавливается как APK.

## Работа с журналом

- Выберите дату. Можно работать с прошлыми днями, затем вернуться кнопкой «Сегодня».
- Каждый физический компонент — одна запись. Авиакомпания, P/N и S/N компонента обязательны. Для колеса также обязательны P/N и S/N шины; наварка и примечания необязательны.
- Номера переводятся в верхний регистр сразу при вводе или вставке, а также при сохранении и импорте. Регистр авиакомпании и примечаний сохраняется.
- Подсказки берутся из истории этого поля. Авиакомпании отсортированы по последнему изменению записи. Поля не заполняются автоматически и не связываются между собой.
- После сохранения очищается **вся форма**, в том числе авиакомпания, отметка 1С и выбор типа возвращается к колесу. Дата и дневной список остаются.
- Черновик сохраняется в IndexedDB при каждом изменении и восстанавливается после открытия. Если появляется ошибка сохранения, не закрывайте приложение до её устранения. Обработчик закрытия даёт дополнительную защиту там, где его поддерживает браузер; принудительное завершение Android может прервать последнюю запись в хранилище.
- «Изменить» открывает запись в форме. Выбор другой даты при редактировании переносит запись после сохранения. Отмена редактирования не меняет сохранённую запись.
- Поиск работает по выбранному дню; флажок «Искать и показывать все даты» включает весь журнал. В этом режиме кнопка Excel всё равно экспортирует **только выбранную дату**, без ограничения поиском.
- В 1С приложение ничего не отправляет: это только личный флажок. В Excel он не попадает, в полной JSON-копии сохраняется.

## Excel и отправка на ПК

Кнопка «Excel за день» каждый раз создаёт настоящий `.xlsx` с актуальными сохранёнными записями выбранной даты. Несохранённый черновик не включается. В файле девять столбцов: дата, авиакомпания, тип компонента, P/N и S/N компонента, P/N и S/N шины, наварка, примечания. Поля номеров хранятся как текст: ведущие нули сохраняются, текст с `=` не превращается в формулу.

Файл появится в «Загрузках» телефона. Откройте приложение «Файлы» → «Загрузки» → выберите XLSX → «Поделиться» (почта, мессенджер, Quick Share) либо перенесите по USB. Отправка выполняется вами, приложение никуда не передаёт журнал самостоятельно.

## Резервные копии — обязательно

В конце рабочего дня: «Данные и установка» → «Сохранить копию JSON». Сначала сохраните текущую запись: черновик не входит в резервную копию. Перенесите JSON с телефона на компьютер/в выбранное вами надёжное место. Проверьте, что файл действительно скачался. Excel не заменяет полную копию.

Для восстановления: сначала сохраните текущую копию → «Восстановить из JSON» → выберите файл → проверьте количество → «Объединить данные». Формат и все записи проверяются до изменения базы; ошибка отменяет импорт. Восстановление выполняется одной транзакцией. Совпадающие идентификаторы объединяются: остаётся запись с более поздним `updatedAt`; при равенстве сохраняется текущая. Отсутствующие в копии записи не удаляются. Импорт старой копии может вернуть ранее удалённые записи. На разных часах устройств сравнение времени может быть неточным — синхронизация устройств не поддерживается.

Удаление приложения, данных сайта/браузера, смена браузера, поломка телефона или нехватка места могут привести к потере локальных данных. Приложение запрашивает устойчивое хранение после сохранения, но браузер может отказать. Не используйте инкогнито. JSON содержит весь журнал открытым текстом — храните его как рабочие данные.

## Новый репозиторий GitHub

В папке подготовлен отдельный Git-репозиторий. Создайте **пустой** репозиторий `aviacontrol` в своём GitHub (без README, лицензии и .gitignore), затем:

```sh
git remote add origin https://github.com/ВАШ_ЛОГИН/aviacontrol.git
git push -u origin main
```

Можно добавить папку через GitHub Desktop → File → Add local repository → Publish repository. Не выбирайте папку WeekendWork. Если старый репозиторий предлагает себя по умолчанию, отмените и укажите именно эту папку.

В `.github/workflows/pages.yml` готова сборка, тесты и публикация на GitHub Pages. В новом репозитории откройте Settings → Pages → Source: GitHub Actions. Публикация исходного кода не публикует журнал: пользовательские записи находятся только в IndexedDB телефона. Для приватных репозиториев доступность Pages зависит от тарифа GitHub.

## Проверки

`npm test` проверяет верхний регистр, обязательные поля и даты, независимые подсказки, фильтр поиска, JSON round-trip и отказ при повреждениях, объединение версий, сохранение/изменение/удаление в IndexedDB, сохранность черновика при отметке 1С, XLSX round-trip, фильтрацию даты, отсутствие 1С и сохранение строковых номеров.

`npm run build` выполняет строгую проверку TypeScript и создаёт service worker с локальным кэшем ресурсов. Реальную установку и авиарежим необходимо дополнительно проверить на вашем Android. В предпросмотре могут быть тестовые записи; в распространяемые файлы пользовательская база не включается.
